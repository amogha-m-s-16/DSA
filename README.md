## 🚀 About This Repository

Welcome to my **Data Structures & Algorithms repository**.

This repository is my personal space for learning, implementing, and mastering **DSA through problem solving**.

> 💡 **The goal isn't just to solve problems — it's to understand why a solution works, analyze its complexity, and build the ability to solve unfamiliar problems.**

Here you'll find implementations, practice problems, optimized solutions, and notes covering everything from fundamental data structures to advanced algorithms.

# ⏱️ Complexity Matters

Every solution focuses on understanding:

```text
┌──────────────────────────────────────┐
│          TIME COMPLEXITY             │
├──────────────────────────────────────┤
│ O(1)        Constant                │
│ O(log n)    Logarithmic             │
│ O(n)        Linear                  │
│ O(n log n)  Linearithmic            │
│ O(n²)       Quadratic               │
│ O(2ⁿ)       Exponential             │
│ O(n!)       Factorial               │
└──────────────────────────────────────┘
```

> ⚡ **Rule:** Don't just ask *"Does it work?"*
> Ask *"Can it be faster?"*

# 🔥 My DSA Philosophy

> **Understand → Implement → Analyze → Optimize → Repeat**

I believe DSA is not about memorizing hundreds of solutions.

It's about developing the ability to look at a problem and think:

```text
"What is the pattern?"
        ↓
"Can I simplify it?"
        ↓
"Can I optimize it?"
        ↓
"What is the complexity?"
        ↓
"Can I do better?"
```
